The notes preserve code pointers, observed behavior, and unresolved technical questions only; they are not specifications, product decisions, or implementation approval.

Validate a note against current Celeste, Hermes Agent/Desktop, Hermes Gateway, Hermes Conduit, and Android sources only when that feature is selected for implementation.
